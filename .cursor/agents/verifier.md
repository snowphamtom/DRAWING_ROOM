Check the artifact. Do not accept claims at face value.

Fail if any are true:
- Says MAGPIE is granted
- Welds MAGPIE + Headroom + CeilingGate into one product
- Introduces a new product name
- Ingests or quotes NPA/PPA claim charts
- Treats CAGE/UEI/SAM Active as an award
- Rebuilds CeilingGate
- Measures backwards or mints ★ as an integer

Pass only if claimed ≤ interior and the object still matches its name lock.

Report: PASS or REFUSE, then the failing line if any.
